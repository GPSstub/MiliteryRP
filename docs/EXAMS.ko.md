# 계급 시험: 개최와 참가

## 이용 방법

- 화면 **오른쪽 통신 버튼 바로 위**에 있는 **◆ 시험**을 누릅니다. 이 버튼은 모든 계급에 표시됩니다.
- 시험 목록에는 현재 서버에서 진행 중인 시험의 **시험 계급, 참가자 수, 개최자의 실제 군 계급과 표시 닉네임·사용자 이름**이 나타납니다.
- 목록에서 시험 하나를 클릭하면 상세 화면에 **현재 참가자 전원의 계급·이름**이 표시됩니다. 일반 플레이어는 **시험 참가하기** 또는 **참가 취소**를 할 수 있습니다.
- **위관급(소위·중위·대위), 영관급(소령·중령·대령), 장관급(준장·소장·중장·대장)** 플레이어만 창설 UI를 볼 수 있습니다. 개최할 계급을 선택해 **시험 창설**을 누릅니다. 개최자는 자기 시험의 **시험 종료**를 눌러 종료할 수 있습니다.
- 시험 대상: **이병 · 일병 · 상병 · 병장 · 하사 · 중사 · 상사 · 원사** (총 8종).

## 운영 정책

- **서버당 동시 최대 6개**의 시험을 개설할 수 있습니다.
- 한 개최자는 동시에 **하나**의 시험만 운영합니다.
- 참가자는 동시에 **하나**의 시험에 참가할 수 있습니다. 개최자는 자신의 시험에 참가할 수 없습니다.
- 개최자가 퇴장하거나 군 계급이 위관 미만으로 변경되면 개최 중인 시험이 자동으로 종료됩니다. 참가자가 퇴장하면 명단에서 제거됩니다.
- 서버가 종료되면 시험은 초기화됩니다. 현재 시스템은 **서버별 임시 시험 모집판**이며 DataStore에 저장하거나 여러 서버 간 시험을 공유하지 않습니다.
- **참가한다고 자동으로 진급하지 않습니다.** 시험 문제, 합격·불합격 판정, 성적, 보상, 관리자 심사, 자동 진급은 아직 구현 범위가 아닙니다.

## 보안과 구현

- 서버 `ExamService.server.luau`에서 `RankService.get(player)`의 **저장된 실제 군 계급**을 확인합니다. 클라이언트가 보낸 계급, 팀 이름, HQ 표시, 그룹 관리자 속성을 개최 권한 근거로 사용하지 않습니다.
- 입장/퇴장/창설/종료는 `ExamRules.luau` 순수 상태 규칙으로 검증하고, 6개 제한과 중복 참가를 서버에서 원자적으로 확인합니다. 비정상적 요청과 반복 요청도 서버에서 거부합니다.
- `ExamBoardRequest`(RemoteFunction)는 현재 시험 스냅샷과 참가 작업에만 쓰고, `ExamBoardChanged`(RemoteEvent)로 수정된 명단을 접속자에게 갱신합니다.
- 개최자와 참가자의 이름은 Roblox가 관리하는 Name/DisplayName 속성을 표시합니다.

## 테스트

1. 일반 계급 사용자로 접속해 **시험** 버튼은 보이지만 **시험 창설**은 보이지 않는지 확인합니다.
2. 소위 이상 사용자로 접속해 **시험 창설**이 보이며 8개 대상 계급이 표시되는지 확인합니다.
3. 소위 이상 6명으로 시험 6개를 만든 뒤 7번째 생성 요청이 서버에서 거부되는지 확인합니다.
4. 일반 사용자 2명이 참가하여 각 시험의 참가자 명단·참가 취소·퇴장 시 제거가 실시간으로 갱신되는지 확인합니다.
5. 개최자 계급을 병장으로 내리거나 개최자를 퇴장시켜 시험이 자동 종료되는지 확인합니다.
6. PC 및 모바일 화면에서 시험 버튼이 통신 버튼 위에 놓이고, 시험창을 닫았다 다시 열 수 있는지 확인합니다.

순수 규칙 테스트는 `tests/exams.spec.luau`, 전체 Luau 구문·순수 회귀 테스트는 `python3 tools/test.py`로 실행합니다. 실제 Roblox Studio 멀티플레이 테스트는 별도로 필요합니다.
