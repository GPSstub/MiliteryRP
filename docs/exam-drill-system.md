# 제식 시험 시스템

완성 맵: `MilitaryRP.rbxlx`. 기존 맵을 유지한 채 첨부 Meshy 훈련장과 시험 기능을 추가했다.

## 사용법

1. 위관·영관·장관급 개최자가 오른쪽 **시험**에서 시험을 창설한다.
2. 해당 시험 계급과 현재 계급이 같은 인원이 참가한다. 최대 30명이다.
3. 개최자 전용 제어판에서 **시험 시작 · 훈련장으로 이동**을 누른다.
4. 시험관은 앞쪽 노란 표식에, 참가자는 그 앞의 흰 선에 한 줄로 배치된다.
5. 개최자가 구령 버튼을 누르면 해당 시험 참가자 화면에 5초 동안 표시된다. 참가자가 직접 동작한다.
6. **시험 종료** 또는 **참가 취소** 시 생존 중인 같은 캐릭터는 원래 위치로 돌아간다. 개최자가 나가거나 부활하면 시험이 종료된다. 참가자가 부활하면 시험에서 빠진다.

구령은 요청한 문구 그대로다: 우향우, 좌향우, 좌향좌, 우향좌, 앞으로서, 뒤로돌아, 시험관 주시.
진행 중인 시험에는 추가 참가할 수 없다. 최대 6개 시험이 각자 배정된 구역에서 동시에 진행된다. 창설 시 빈 구역 번호가 자동 배정되고, 종료하면 해당 번호를 다시 사용할 수 있다.
자동 합격·승급이나 캐릭터 방향 강제 변경은 하지 않는다.

## 맵과 모델

- `Workspace.ExamDrillGround` 중심은 `(350, 0, -180)`이며, 기존 맵 동쪽에 배치했다.
- 탐색기에서 `Workspace → ExamDrillGround → ExamPositions → Exam1 ~ Exam6`을 펼친다.
- 각 구역의 노란 `ExaminerPoint`는 시험관 위치이고, 파란 `ParticipantLine`은 참가자 줄의 중앙이다.
- Studio의 이동/회전 도구로 표식을 옮기면 다음 시험 시작부터 반영된다. 표식의 화살표는 바라보는 방향이다. 실행 중인 시험의 인원을 즉시 재이동하지는 않는다.
- 파란 표식의 Attributes에서 `ParticipantSpacing`을 바꾸면 간격을 3~10 stud로 조정할 수 있다. 기본값은 4이다.
- `HeightOffset`은 표식 위에서 캐릭터가 나타나는 높이이며 기본 2.94 stud이다. 일반적으로 그대로 두고 표식을 바닥에 놓으면 된다.
- 표식/화살표/설명은 편집할 때만 보이고 게임 실행 중에는 숨겨진다. 표식 이름과 폴더 이름은 유지한다.
- 참가자 간격은 4 stud이며 UserId 순서로 배치한다.
- 모델은 제공된 ZIP에서 변환했다. 917,480 → 239,998 삼각형, 16개 조각(각 최대 15,000), 원본 UV와 경계 노멀 유지, 원본 4K 색상·노멀 텍스처.
- 모델은 시각용이며 별도 `WalkableFloor`가 발판 역할을 한다.
- `assets/drill-ground/ExamDrillGroundHQ.fbx`는 고품질 재가져오기용이다. 이전 18,000 삼각형 버전은 `ExamDrillGround.fbx`로 남겨 두었다. 이미 완성 맵에는 업로드된 메시와 텍스처 참조가 들어 있다.
- 재생성: Blender를 백그라운드로 실행하고 `tools/prepare_drill_ground.py -- --archive <제공된 ZIP 경로>`를 지정한다.
- 기존 외형 교체는 `tools/upgrade_drill_ground.studio.luau`로 하며 시험 위치와 발판은 보존한다.
- Studio 재설치용 위치 설정은 `tools/install_drill_ground.studio.luau`에 있다.

## 검증

전체 소스 컴파일 및 회귀 테스트 통과. 시험 규칙은 기존 포함 128개 검증을 통과했다.
Studio에서는 6개 구역과 24명 모의 캐릭터를 사용하여 동시 배치, 변경한 위치·회전·간격·높이, 구역별 종료/취소 복귀, 다른 시험과의 분리, 캐릭터 누락을 검증한다.
실제 플레이어의 순간이동/복귀, 실제 RemoteFunction의 빈 시험 시작 차단·부적절한 구령 차단, RemoteEvent의 클라이언트 구령 표시도 확인했다.
테스트: `tests/studio/exam-formation-check.luau` (플레이 서버에서 실행, 계급 저장소 변경 없음).
실제 두 클라이언트를 연결한 동시 참가 시험은 별도로 확인해야 한다. 게시하지 않았다.
