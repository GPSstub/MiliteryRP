# 현재 서버의 메시지·명령어 로그

AdminLogService는 DataStore/OrderedDataStore를 읽거나 쓰지 않고, 현재 서버 프로세스의 메모리에 필터링된 기록만 보관합니다. 서버가 종료되면 사라지며 새 서버는 빈 기록으로 시작합니다. 다른 서버의 기록은 조회하거나 공유하지 않습니다. 같은 서버에 재접속하면 해당 서버가 살아 있는 동안의 기록을 볼 수 있습니다.

운영진 그룹 권한, 조회 제한, 채널별 내용 가림, Roblox 텍스트 필터링은 유지합니다. 최신/이전 기록 조회는 현재 서버에서만 페이지를 나눕니다. 기존 영구 로그 데이터는 삭제하지 않으며 새 버전은 조회하지 않습니다. 공지·규칙 등 명시적으로 영구 보관한 게시판과 계급/권한 설정은 이번 변경 대상이 아닙니다.

순수 테스트에서 별도 서버 저장소 간 격리, 새 저장소 초기화, 종류별 분리, 새 기록이 추가되어도 중복 없는 페이지 조회를 검사했습니다. Studio에서도 별도 저장소가 빈 상태로 시작하고 AdminLogService에 DataStore 의존성이 없는 것을 확인했습니다. 실제 다중 서버 통합 테스트는 수행하지 않았습니다.
