# 시험 제한과 모바일 UI

- 개최와 참가를 합쳐 한 사람당 진행 중인 시험은 1개입니다. 시험 종료·참가 취소·퇴장 시 제한이 풀립니다.
- 참가자는 현재 서버에서 확인된 계급이 시험 계급과 정확히 같아야 합니다. 이병 시험은 이병만, 하사 시험은 하사만 참가할 수 있습니다. 계급 정보가 아직 준비되지 않았다면 참가를 거절합니다.
- 계급은 요청 데이터 대신 서버 RankService에서 읽습니다. 참가 중 계급이 변경되어 조건을 벗어나면 명단에서 제거합니다. 개최 권한을 잃으면 해당 시험을 종료합니다. 참가 자체가 진급이나 합격을 의미하지 않습니다.
- 서버 전체 시험 수 제한(6개)과 기존 개최 권한은 유지합니다.

모바일의 시험 화면은 글자를 축소하는 대신 세로 스크롤로 재배치합니다. 메뉴·게임패스·통신 창은 안전 영역 크기를 사용하고, 운영진 메뉴는 좁거나 낮은 화면에서 가로로 스크롤됩니다. 통신 설정의 확인 창도 스크롤할 수 있습니다. 창을 열면 다른 메뉴 버튼과 총기/비행/상황별 조작 UI를 잠시 숨겨 겹침을 줄입니다. 달리기·재장전 버튼은 오른쪽 화면 안쪽에 배치합니다.

검증: 전체 Luau 컴파일·회귀 테스트, 시험 106개 검증 항목, Studio 서버에서 8개 시험 계급의 일치/불일치 검사, 실제 RemoteFunction 중복 개최 거절/종료를 확인했습니다. iPhone XR 시뮬레이터의 가로 801×413, 세로 413×814 화면에서 시험·메뉴·운영진·통신 화면을 확인하고, 최종 재시작 후 창 열기/닫기 시 버튼 숨김과 복귀도 검사했습니다. 실물 휴대폰의 키보드 및 다중 클라이언트 통합 테스트는 별도로 필요합니다.
