# AK 기본 지급 소총

AK는 기존 HK416과 별개의 `AKRifle` 무기이며 모든 플레이어에게 캐릭터 생성 시 1정 지급합니다. HK의 게임패스 ID와 소유권 검증은 변경하지 않습니다.

- 30발 탄창, 예비 탄약 무제한, 0.16초 발사 간격, 1.8초 재장전, 데미지 12, 사거리 300 studs.
- PC 클릭 사격 / R 재장전, 모바일 재장전 버튼, 독립 HUD·반동·1인칭 뷰모델.
- 서버가 지급한 Tool 세션, 장착 상태, 생존, 발사 간격, 탄약, 유효 좌표, 벽 관통 및 아군 피해를 검증합니다.
- `MagazineJoint` Motor6D의 피벗은 탄창 삽입부입니다. 재장전 시 탄창이 빠졌다 복귀합니다.
- 본체 3,992 + 탄창 728 = 4,720 삼각형. 둥근 모서리, 6각 원통, 공유 색상 텍스처.

## 파일과 모델

`assets/ak/AK_source.blend`는 Blender 원본, `AK_Roblox.glb`는 임포트 원본입니다. Studio GLB 임포터의 축 변환은 `src/server/AKMeshConfig.luau`의 장착 회전으로 보정합니다. 원본 파일의 축을 다시 변환하면 이 회전도 재검증해야 합니다.

업로드 소유자는 이 경험의 CURTLE team입니다. 본체 `80809581652817`, 탄창 `108435614268341`, 텍스처 `125025670845510`.

`ServerStorage/AKAssets`가 있으면 그 MeshPart를 복제하며, 없으면 위 메시 ID로 서버가 자동으로 템플릿을 로드합니다. 다른 경험으로 옮길 때는 메시 사용 권한을 별도로 부여해야 합니다. 수동 재임포트 시 `tools/install_ak.studio.luau`를 사용합니다.

## 검증 (2026-10-22)

- 전체 Luau 컴파일 및 순수 회귀 테스트 통과. AK/HK 무기 ID·이름과 탄약 상태가 독립적임을 검사.
- 국군 생활 RP (placeId 86856458100029) 단일 클라이언트 Studio 플레이: 기본 지급, 장착, 독립 HUD, 전방 방향 dot=1, 메시 및 텍스처 확인.
- 클라이언트 RemoteEvent를 통한 사격: 30→29발, 테스트 표적 체력 100→88.
- 문자열·NaN·무한대 좌표 거부, 즉시 중복 사격 거부.
- 재장전 도중 탄창 이동, 완료 후 30발 및 Motor6D 원위치 복귀.
- 플레이를 다시 시작했을 때 중복 없이 기본 지급.
- 서버에서 업로드된 본체/탄창 ID를 CreateMeshPartAsync로 다시 로드하는 검사 통과.

다중 클라이언트 동시 사격, 모바일 실기기, R6 자세는 이번 작업에서 별도로 검증하지 않았습니다. 기존 맵의 `203785492` 자산 종류 불일치 로그는 AK와 무관한 기존 경고입니다. GitHub 반영은 Roblox 라이브 게시와 별개입니다.
