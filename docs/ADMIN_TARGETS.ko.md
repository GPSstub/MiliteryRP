# 관리자 명령어: 사용자 이름 일부 · 표시 닉네임 검색 · 중복 선택창

적용 브랜치: [GitHub main](https://github.com/GPSstub/MiliteryRP/tree/main)

## 동작 방식

Roblox 그룹 `1101574390`의 **그룹 랭크 200 이상** 운영진만 대상 선택과 관리자 명령을 실행할 수 있습니다. HQ 팀인지 여부는 관리자 권한과 무관하며, 그룹 200이라는 기준은 그대로 유지했습니다.

**Roblox 실제 사용자 이름(Name)과 표시 닉네임(DisplayName)을 모두 검색**합니다. 대소문자를 구분하지 않으며, 한글 표시 닉네임과 띄어쓰기가 있는 표시 닉네임도 사용할 수 있습니다.

| 채팅 명령 예시 | 동작 |
|---|---|
| `;to risa` | 이름이나 표시 닉네임이 `risa`로 시작하는 플레이어에게 이동 |
| `;here 철수` | 표시 닉네임 `철수`인 플레이어를 내 옆으로 소환 |
| `;kill 파란 거북이` | 띄어쓰기가 있는 표시 닉네임도 검색 |
| `;폭발 김` | 표시 닉네임이 `김`으로 시작하는 대상에게 폭발 |
| `;계급 철 대위` | 표시 닉네임 일부로 대상 계급 변경 |
| `;팀 @ActualUsername HQ` | `@`를 붙이면 실제 사용자 이름으로만 검색 |
| `;무적 파란 거북이 켜기` | 표시 닉네임을 찾아 무적 활성화 |
| `;비행 risa 끄기` | 이름 일부를 찾아 비행 해제 |

먼저 **정확히 일치하는 이름/표시 닉네임**을 찾고, 그다음 **앞부분 일치**, 마지막으로 **일부 포함** 순으로 검색합니다. 가장 높은 우선순위에서 한 명만 일치하면 바로 명령을 실행합니다. 최상위 일치 대상이 여러 명이면 **한 명도 자동으로 선택하지 않고 대상 선택창을 띄웁니다.**

### 중복일 때 화면

서버에서 두 명 이상 일치하면 관리자 화면 위에 후보 선택창이 자동으로 열립니다. 채팅 명령과 어드민 패널의 직접 명령/플레이어 제어/계급/팀 관리 버튼에 동일하게 적용됩니다.

후보에는 두 이름이 모두 보입니다.

- 표시 닉네임 (DisplayName)
- `@실제사용자이름` (Name) 및 Roblox UserId

**선택 버튼을 누르기 전까지 사망·순간이동·팀/계급 변경 같은 명령은 실행되지 않습니다.** 창의 **취소**를 누르거나 Esc를 누르면 아무 대상도 조작하지 않고 끝납니다. **30초 안에 선택**하지 않으면 요청이 만료됩니다.

서버는 선택창에 제시한 후보 UserId와 요청 번호를 별도로 보관합니다. 임의의 UserId를 보내거나 이미 사용한 요청 번호를 다시 전송해도 명령이 실행되지 않습니다. 실행 직전에는 **Roblox 그룹 관리자 등급을 다시 확인**합니다.

새 관리자 명령을 입력하면 이전에 띄워둔 후보 선택 요청을 취소합니다.

## 제한 사항

- 대상은 **현재 서버에 접속한 플레이어** 중에서 찾습니다. 게임 밖에 있는 플레이어의 표시 닉네임은 검색하지 않습니다.
- `나` 또는 `me`는 언제나 자기 자신을 뜻합니다.
- `all`, `everyone`, `모두`, `전체`처럼 서버 인원을 일괄 조작하는 단축 대상은 지원하지 않습니다.
- Roblox에서 표시 닉네임을 동일하게 설정한 사용자가 여러 명이어도 이름을 추측해 첫 번째 플레이어에게 실행하지 않습니다.
- 강제로 특정 Roblox 계정을 선택하려면 `@실제사용자이름`을 입력하세요. `@`는 표시 닉네임을 검색하지 않습니다.

## 소스 파일

- `src/server/AdminTargetMatch.luau`: 실제 사용자 이름과 표시 닉네임 매칭 및 우선순위 결정
- `src/server/AdminTargetSelection.luau`: 서버에 후보/기한 저장, 유효성 검사, 선택한 대상에 실행
- `src/client/AdminTargetPicker.client.luau`: 모바일/PC에서 표시하는 후보 선택창
- `src/server/AdminService.luau`: 무적·비행·팀·순간이동·사망·폭발 명령 대상 통합
- `src/server/RankCommands.luau` / `RankCommandParser.luau`: 계급 명령 대상 통합
- `src/server/AdminPlayerCommandParser.luau`: 띄어쓰기 포함한 표시 닉네임 처리
- `src/client/AdminPanel.luau`: 관리자 패널의 대상 안내 및 선택 결과 연동
- `tests/admin-target-match.spec.luau`, `tests/commands.spec.luau`, `tests/admin-player-actions.spec.luau`: 순수 로직 테스트
- `tests/studio/admin-semicolon-check.luau`: Studio 명령·대상 선택 RemoteEvent 등록 확인

## 적용 / 테스트

```bash
git status --short
git switch main
git pull --ff-only origin main
rojo serve default.project.json
```

Studio에서 Rojo 재연결 후 Stop → Play로 새로 실행하세요. **그룹 랭크 200 이상인 운영진**과 일반 플레이어 **2~3명**을 함께 접속시켜 다음을 확인합니다.

1. 서로 다른 사용자 이름이지만 **같은 표시 닉네임**(예: `철수`)을 가진 계정 2명 접속.
2. 운영진이 `;to 철수` 입력 → 후보 선택창 표시, 대상 선택 전까지 순간이동되지 않음.
3. 목록에서 원하는 `@사용자이름`을 클릭 → **선택한 계정에만** 순간이동.
4. `;계급 철수 대위`, `;kill 철수` 등도 후보 선택 후에만 실행되는지 확인.
5. 다른 운영진 명령을 입력하거나 취소하면 이전 선택 번호로 실행되지 않는지 확인.
6. `@사용자이름`을 완전히 입력하면 올바른 계정이 자동 선택되는지 확인.
7. 그룹 등급 200 미만 계정은 클라이언트 RemoteEvent를 직접 호출해도 명령이 실행되지 않는지 확인.

**검증 상태:** GitHub 소스 및 회귀 테스트를 추가했으나 실제 Roblox Studio 다중 클라이언트 플레이 테스트는 이 환경에서 수행하지 못했습니다.
