# HQ 팀 · Roblox 그룹 운영진 권한 · 어드민 패널

**그룹 ID: `1101574390` | 임시 관리자 권한 기준: 그룹 랭크 200 이상.** 구체적인 설정/검증 방법은 [그룹 관리자 권한 안내](GROUP_ADMIN.ko.md)를 먼저 확인하세요.

## 팀은 소속, 그룹은 관리 권한

`default.project.json`과 `TeamService`는 네 개의 Roblox `Teams`를 생성합니다. 모든 팀은 `AutoAssignable=false`입니다.

| 팀 | 배정 방식 | 관리자 명령·패널 권한 |
|---|---|---|
| **HQ** | 현재 서버의 그룹 관리자가 `;팀 대상 HQ`로 임명. 제작자 계정은 접속 시 시각적인 HQ 팀에 초기 배정 | **그룹 랭크 200 이상일 때만** |
| 위관급 | 소위·중위·대위 계급으로 자동 배정 | 그룹 랭크에 따름 |
| 영관급 | 소령·중령·대령 계급으로 자동 배정 | 그룹 랭크에 따름 |
| 장관급 | 준장·소장·중장·대장 계급으로 자동 배정 | 그룹 랭크에 따름 |

훈련병·병·부사관·준위는 일단 별도 팀 없이 미배정(`Neutral`) 상태입니다.

**중요:** HQ 팀에 들어갔다고 관리자 권한이 생기지 않습니다. HQ 팀은 머리 위 거북이·고양이 로고와 `HQ` 표시, 팀 소속과 임시 `admin` 계급 표시용입니다. 관리자 권한은 Roblox 그룹 역할로만 확인합니다. HQ 팀은 세션 전용일 수 있어도 그룹 운영진 권한은 Roblox 그룹에 저장되어 재접속 시 다시 조회됩니다.

## 관리자 명령·로그 보안

- 그룹 랭크 **200–255** 계정만 Roblox 기본 채팅창 또는 관리 패널에서 `;` 명령을 실행할 수 있습니다.
- 명령 예시: `;계급 나 대위`, `;계급목록`, `;팀 대상 HQ`, `;무적 나 켜기`, `;비행 나 켜기`, `;to 대상`, `;here 대상`, `;kill 대상`, `;폭발 대상`.
- 어드민 패널, 관리 명령 RemoteEvent, `TextChatCommand`, 팀 배정, HQ 영구 채팅·명령 로그 조회는 서버의 같은 그룹 권한 판정을 사용합니다.
- 클라이언트에서 메뉴나 `CanUseAdminCommands` 속성을 임의로 바꿔도 서버의 권한 검사를 통과하지 못합니다.
- 그룹에서 운영진을 임명하거나 내린 뒤 **게임에 다시 접속**하여 역할이 반영되는지 확인하세요. Roblox 그룹 API가 현재 서버 세션에서 캐시될 수 있습니다.
- 일반 군 계급에 따른 메신저 채널/역할 접근권한과 공지·규칙 영구 저장 정책은 기존대로 유지됩니다.

## 어드민 패널

`메뉴 → 운영진 패널`에서 다음 기능을 제공합니다.

- **개요:** 접속 인원·팀별 현황과 빠른 이동 버튼
- **인원 관리:** 실제 사용자 이름 일부·표시 닉네임(DisplayName) 검색 및 동명이인 후보 선택창 ([동작 설명](ADMIN_TARGETS.ko.md))
- **계급:** 20개 군 계급을 선택하여 서버 DataStore에 저장
- **팀 관리:** HQ·위관급·영관급·장관급 팀 배정 (HQ 배정은 **관리자 권한을 부여하지 않음**)
- **무적/비행:** 켜기·끄기
- **플레이어 제어:** 순간이동(`to`), 소환(`here`), 사망(`kill`), 폭발 효과(`폭발`)와 위험 작업 확인창
- **직접 명령어:** `;` 형식의 명령 실행 및 예시. 중복 닉네임은 화면에서 한 명을 선택해야 적용
- **서버 기록:** 채팅·명령어 로그를 분리해 영구 조회. 자세한 사항은 [서버 로그](HQ_SERVER_LOGS.ko.md) 참조

## 적용

```bash
git status --short
git switch main
git pull --ff-only origin main
rojo serve default.project.json
```

Studio에서 Rojo를 연결하고 Stop → Play로 재시작하세요. 게시된 경험에서 실제 그룹 운영진 계정을 사용한 테스트가 필요합니다.

1. 실제 그룹 랭크 200 이상 계정 접속 → `AdminGroupStatus=Ready`, `CanUseAdminCommands=true` 확인.
2. 해당 계정을 HQ가 아닌 팀으로 이동해도 명령어와 패널이 유지되는지 확인.
3. 일반 그룹원을 HQ 팀에 배정해도 관리자 기능과 로그가 열리지 않는지 확인.
4. 그룹 역할을 바꾼 후 재접속하면 권한이 변경되는지 확인.
5. `tests/admin-group-policy.spec.luau`, `tests/studio/hq-team-check.luau`로 정책 확인.

**검증 상태:** GitHub 소스 및 정책 테스트는 반영했지만 Roblox Studio에서 실제 그룹 로그인 통합 테스트는 아직 진행하지 못했습니다.
