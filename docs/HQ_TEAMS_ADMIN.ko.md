# HQ 팀 편제 · 관리자 권한 · 통제 패널 (2026-10-20)

소스 브랜치: [main](https://github.com/GPSstub/MiliteryRP/tree/main)

## 네 개의 Roblox 팀

Rojo `default.project.json`에 네 개의 실제 `Teams` 인스턴스를 선언했습니다. 게임 서버의 `TeamService`가 시작할 때 팀이 없더라도 생성하고, 각 팀 `AutoAssignable=false` 및 고유 `TeamColor`를 보장합니다.

| 팀 | 가입 방식 | 관리자 명령/패널 |
|---|---|---|
| **HQ** | HQ 관리자가 `/팀 대상 HQ`로 임명. 기존 제작자 계정은 접속 시 초기 HQ로 배정 | **허용** |
| 위관급 | 소위·중위·대위 계급으로 자동 배정 | 차단 |
| 영관급 | 소령·중령·대령 계급으로 자동 배정 | 차단 |
| 장관급 | 준장·소장·중장·대장 계급으로 자동 배정 | 차단 |

훈련병, 병, 부사관, 준위는 아직 요청된 네 팀에 해당하지 않으므로 **팀 미배정(Neutral)** 상태로 남습니다. 추가 일반병사 팀은 생성하지 않았습니다.

## 권한 정책 (게임 서버에서 재검증)

- `/계급`, `/계급목록`, `/rank`, `/ranks` 는 **현재 HQ 팀에 배정된 사용자만** 실행할 수 있습니다.
- 패널 경유 `/팀`, `/team`, `/무적`, `/god`, `/비행`, `/fly` 또한 현재 HQ 팀 사용자만 실행할 수 있습니다.
- 관리 패널 UI는 HQ 소속일 때만 메뉴에 표시되며, HQ에서 나가면 즉시 닫힙니다. 화면을 강제로 열거나 RemoteEvent를 보내도 서버가 요청을 거절합니다.
- HQ 팀은 군 계급과 독립적입니다. 진급만으로 HQ 권한을 얻지 못합니다. HQ에 있을 때 계급을 변경해도 HQ를 유지하며, HQ에서 나가면 명령 권한이 즉시 해제됩니다.
- 제작자 계정 `1153125948`은 접속할 때 관리 권한을 잃지 않도록 HQ로 초기 배정합니다. 다른 사용자를 HQ로 이동시키려면 이미 HQ인 사용자의 서버 명령이 필요합니다. **누군가를 HQ로 지정하면 즉시 모든 관리 권한이 생기므로 신중하게 사용하세요.**
- **수동 팀 배정은 현재 서버 세션에만 적용됩니다.** 재접속하면 제작자는 HQ로 초기화되고, 다른 사용자는 저장된 계급에 따라 위관급/영관급/장관급으로 다시 배정됩니다. HQ 배정을 영구 저장하는 기능은 이번 범위에 포함하지 않았습니다.
- 기존 메신저 설정/역할 권한 시스템은 별도로 동작합니다. 이번 변경에서 메신저 권한을 일괄 HQ 전용으로 만들지 않았습니다.

## 개편한 어드민 패널

`메뉴 → HQ 관리 패널`에서 다음 기능을 제공합니다.

- 통제실 개요: 서버 접속 인원과 HQ/위관/영관/장관별 인원수 표시
- 플레이어 선택: 온라인 플레이어 목록 및 Roblox 사용자 이름 직접 입력
- 무적/비행 제어: 활성화·비활성화를 분리해 한 번에 실행
- 팀 관리: 4개 팀 중 선택해 적용, **HQ 승격 시 확인창**
- 계급 관리: 훈련병부터 대장까지 계급을 범주별로 선택한 후 저장
- 명령어: 사용 예시, 편집 입력창, 명령 실행
- 기록: 현재 서버의 최근 관리자 실행 결과 최대 60개, 성공/실패 색상 구분
- 모바일/좁은 화면에서 탭은 수평 이동 가능한 영역으로 변경

## 동기화

기존 로컬 변경 사항을 확인한 다음:

```bash
git status --short
git switch main
git pull --ff-only origin main
rojo serve default.project.json
```

Rojo Studio 플러그인으로 연결한 뒤 테스트합니다.

1. Explorer의 `Teams` 서비스에 `HQ`, `위관급`, `영관급`, `장관급`이 있는지 확인합니다. 모든 팀은 `AutoAssignable=false`입니다.
2. 제작자 계정으로 Play → `HQ`에 배정되고 `메뉴 → HQ 관리 패널`이 표시되는지 확인합니다.
3. 다른 플레이어로 Start Server / 2 Players 테스트 → 관리자 패널이 표시되지 않고 `/계급목록`도 거부되는지 확인합니다.
4. HQ 패널에서 다른 플레이어에게 `대위` 계급 부여 → 해당 플레이어가 `위관급` 팀으로 이동하는지 확인합니다.
5. HQ 패널에서 `위관급` 플레이어를 `HQ`로 이동 → 확인창이 뜨고 승인 후 대상에게 관리 패널이 표시되는지 확인합니다.
6. HQ 플레이어를 `영관급`으로 이동 → 관리 패널이 자동으로 닫히고 명령어 실행이 서버에서 거부되는지 확인합니다.
7. 기존 계급 DataStore와 메신저 채널/권한/영구 공지 저장이 여전히 정상인지 확인합니다.

순수 Luau 테스트: `python3 tools/test.py` (공식 `luau`, `luau-compile` CLI 설치 필요). `tests/team-policy.spec.luau`는 팀 목록·계급별 자동 편제 및 HQ 권한 규칙을 확인합니다.

**테스트 상태:** GitHub 소스 수정은 완료했지만, 이 환경에서는 Roblox Studio/공식 Luau CLI를 실행할 수 없어 통합 테스트 완료를 주장하지 않습니다.

관련 공식 문서: [Roblox 팀 구현](https://create.roblox.com/docs/players/teams), [Team 클래스](https://create.roblox.com/docs/reference/engine/classes/Team).
