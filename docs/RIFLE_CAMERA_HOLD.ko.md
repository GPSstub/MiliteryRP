# 총구·손 고정 및 1인칭 카메라 대응

## 반영 내용

사용자가 조절한 `BASE_GRIP=CFrame.new(0,0.1,-0.3)`, 탄창 삽입 지점 `(0,0.40,-1)`과 각도 `15`를 보존했습니다. 이전 문서/manifest의 탄창 각도는 교체 당시 값이며, 현재 런타임 배치는 `TrainingRifle.server.luau`가 기준입니다.

- 총구 Attachment를 Handle의 임의 좌표에서 실제 `HK416Body`의 FBX 총구 끝으로 옮겼습니다. 경량화된 FBX의 끝단 정점들을 측정해 기준점을 정했고, 총몸 로컬 좌표 `(0.04483,0.32258,2.88072) × 0.64`, Y축 180도 방향으로 생성합니다. 총몸의 방향을 따라갑니다.
- 총구 불꽃은 `EmissionDirection=Front`, `LockedToPart=true`로 총열 전방을 향합니다. 실제 서버 Raycast와 외부에 보이는 탄흔은 이 총구에서 시작합니다.
- R15는 기본 RightGrip 연결이 생성되고 정상적으로 앞을 보는 자세가 된 뒤 UpperTorso~Handle Motor6D로 총을 고정합니다. 오른손과 왼손은 IK로 무기를 따라갑니다. 장착 대기는 최대 4초로 제한되며 해제/사망/파괴 시 취소됩니다. 재장전 및 반동은 의도한 포즈 변화로 유지합니다.
- 서버의 기본 손 애니메이션 전달이 늦어도 팔이 아래로 떨어진 초기 자세를 고정하지 않습니다. 총의 잡는 위치를 유지하고, 고정 시 방향은 캐릭터 전방과 수평을 기준으로 정합니다. 이후에는 몸통 회전과 함께 움직입니다.
- 장착 해제, 사망, Tool 파괴 시 Motor6D·양손 IK·타깃을 정리하고 남아 있는 기본 RightGrip 연결을 복원합니다. R6는 기존 기본 그립 방식을 유지합니다.
- 1인칭에서는 로컬 카메라 아래 별도 총/팔 표시 모델을 만들고 실제 캐릭터의 총/팔은 해당 플레이어에게만 숨깁니다. 카메라 상하·좌우 회전을 따라가며 실제 탄창/노리쇠 및 재장전 포즈를 복사합니다. 3인칭 전환 또는 무기 해제 시 표시 모델을 제거하고 원본 표시를 복원합니다.
- 1인칭 전용 모델은 충돌·터치·공간 쿼리가 없으며 서버에 복제되지 않습니다. 서버에서 승인한 명중 지점으로만 시각적 탄흔을 그립니다. 자기 자신의 서버 탄흔은 1인칭에서 숨기고 카메라 모델의 총구에서 연결합니다. 다른 플레이어에게는 실제 무기의 총구와 서버 탄흔이 보입니다.

## 직접 조절할 값

`src/client/RifleViewmodel.luau`의 `CAMERA_GRIP=CFrame.new(0.60,-0.70,-0.75)`는 1인칭 화면에서 손잡이의 카메라 기준 위치입니다. X는 화면 오른쪽, Y는 위쪽, Z 음수는 화면 안쪽입니다. 이 값을 바꿔도 3인칭 총 배치나 명중 판정은 바뀌지 않습니다.

3인칭 총/탄창 배치는 기존처럼 서버 스크립트의 BASE_GRIP 및 탄창 position에서 조절합니다. 1인칭에서 보이는 총구 위치는 별도 가짜 명중 판정을 만들지 않습니다. 벽에 총구가 가려졌거나 잘못된 좌표/연사 간격/탄약 상태면 서버가 발사를 차단합니다.

## 검증

- 전체 Luau 소스 컴파일 및 기존 순수 회귀 테스트 통과.
- Studio 실제 R15 플레이: 이동 중 몸통 기준 무기 각도 변화 0도, 위치 변화 약 0.00025 studs 이하 확인(의도적인 반동/재장전 제외).
- 카메라 상하·좌우 회전 시 카메라 기준 무기 각도 오차 0도, 위치 오차 약 0.000065 studs 이하.
- 서버 탄흔의 시작점과 실제 총구 차이 약 0.0000007 studs. 정지된 1인칭 화면에서 전용 탄흔과 카메라 총구 시작점 차이 0.
- 사격 시 탄약 감소와 표적 피해 12 확인. 재장전 후 탄약 보충 및 탄창 위치/각도 복귀 오차 0 확인.
- 3인칭 전환 시 표시 모델 제거 및 원본 총 표시 복원 확인. 장착 해제 후 잔여 양손 IK, 고정 Motor6D, 타깃 0개 확인. 반복 장착/해제 시 정상 Humanoid 상태 및 기존 이동 유지 확인.

Studio에서 서버 1개/플레이어 1명으로 검증했습니다. 실제 다중 클라이언트 및 DataStore 통합 검증/공개 경험 배포는 수행하지 않았습니다. 배포 전 AGENTS.md의 통합 검증은 별도로 수행해야 합니다.
