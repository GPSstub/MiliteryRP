# 첨부 FBX 기반 HK416 교체 — 2026-10-21

이번 버전은 기존 OBJ 메시를 사용하지 않습니다. 사용자가 제공한 아래 두 ZIP에서 각각 총몸과 탄창을 가져왔습니다.

- `Meshy_AI_hk416_rifle_body_1021133615_texture_fbx.zip`
- `Meshy_AI_hk416_magazine_1021140458_texture_fbx.zip`

원본 파일 해시 및 Roblox 메시/텍스처 ID는 `assets/hk416/manifest.json`에 있습니다. 총몸 15,913개, 탄창 15,559개 삼각형으로 경량화했으며 원본 UV와 Color/Normal/Metalness/Roughness 맵을 유지했습니다.

## 최종 보정

- 원본 좌표를 무기 좌표로 바꾸는 과정의 반사 변환 때문에 면 방향이 뒤집히는 것을 수정했습니다. 면 순서를 반전하여 signed volume이 두 메시 모두 양수임을 확인했습니다. `DoubleSided=false`에서도 외부 표면이 보입니다.
- 총몸은 Y축 180도 회전으로 메시의 총열을 총구 Attachment의 -Z 방향에 맞춥니다. Tool 자체의 Yaw는 0도입니다.
- R15 손목 기울기를 Grip X축 16도로 보정했습니다. 장착 후 총구/캐릭터 전방 내적 약 0.9998, 총구 수직 성분 약 0.003~0.008로 확인했습니다. 체형 및 기본 애니메이션에 따라 조금 달라집니다.
- 총몸 손잡이 기준점, 총구, 노리쇠 및 왼손 타깃을 새 FBX 기준으로 배치했습니다.
- 탄창은 별도 생성 모델이므로 총몸과 같은 Y축 회전을 적용하지 않습니다. 중심은 원본 무기 좌표 `(0,-0.24,-1.08)`에 모델 배율 0.64를 적용합니다. 기존 시안보다 위로 0.0576, 앞으로 0.1152 studs 이동한 위치입니다.
- 사용자 피드백에 따라 삽입 지점 `(0,0.39,-1.08)`을 중심으로 X축 -8도 기울여 탄창 밑부분이 개머리판을 향하게 했습니다. 탄창 상단의 결합 위치는 유지됩니다.
- 재장전 Motor6D는 이 위치와 각도로 복귀하며, 탄창 추출은 총몸 기준 아래 방향으로 이동합니다.
- 서버에서 승인된 발사에만 클라이언트 반동을 적용합니다. 탄약/연사/벽/팀/좌표 검증은 서버에 유지됩니다.

## 파일과 적용

`MilitaryRP.rbxlx`는 기존 완성 맵에 새 `ServerStorage/HK416Assets`와 최신 스크립트를 포함합니다. Workspace 1,380개 인스턴스는 변경 전과 XML 파싱 결과가 동일합니다. `tools/build_place.py`로 완성 맵을 덮어쓰지 마세요.

`assets/hk416/HK416Assets.rbxmx`는 동일한 두 MeshPart와 SurfaceAppearance를 포함한 별도 모델입니다. 다른 맵에서는 이 폴더를 ServerStorage에 넣으면 됩니다. 기존 같은 이름 폴더는 먼저 별도 이름으로 백업해야 합니다. Rojo의 ServerStorage는 관리 대상이 아니므로 코드 동기화만으로 새 모델이 설치되지는 않습니다.

FBX 재생성은 Blender에서 `tools/prepare_hk416.py`를 실행하고 두 ZIP 경로를 전달합니다. 원본은 수정하지 않습니다. 재생성 FBX를 Studio에서 다시 업로드했다면 새 ID와 모델 사본도 함께 갱신해야 합니다.

## 검증 결과

- 전체 Luau 소스 컴파일 및 기존 순수 테스트 통과.
- Python place-builder 테스트 2개 통과.
- Studio의 실제 서버/클라이언트 플레이에서 새 메시 ID 및 R15 왼손 IK 확인.
- 10개 동시 발사 요청에서 탄약 1발 소비, 표적 피해 12 확인.
- 문자열, NaN, 무한대, 뒤쪽 목표 요청은 탄약을 소비하지 않음.
- 머리~총구 사이 장애물이 있으면 발사 차단.
- 재장전 중 발사 차단, 탄창 아래로 추출 및 원위치 복귀, 탄약 `29/90 → 30/89` 확인.
- 수정된 표면과 최종 탄창 배치는 별도 재시작 후 시각적으로 확인.

다중 클라이언트/실제 DataStore 통합 테스트와 공개 경험 배포는 수행하지 않았습니다. 이번 작업은 데이터 저장 코드를 변경하지 않습니다. 게임 배포 전에는 AGENTS.md의 통합 검증을 별도로 수행해야 합니다.

## Studio 출력 오류

`cloud_8510540480.HTML...AppData` 오류는 설치된 HTML 플러그인에서 발생했습니다. Plugin Management에서 해당 플러그인을 비활성화한 뒤 재시작한 Play에서는 이 오류가 사라졌습니다. 이 설정은 현재 컴퓨터의 Studio 설정이며 Git 파일로 전달되지 않습니다.

Roblox CorePackages의 FoundationProvider 경고 및 `rbxassetid://203785492` 타입 오류는 여전히 발생합니다. 해당 ID는 저장소 및 게임 스크립트에서 발견되지 않았고 새 총기 메시/텍스처 ID에도 포함되지 않습니다. 원인이 확인되지 않은 이 항목은 수정 완료로 간주하지 않습니다.

이 문서는 현재 최종 버전이며 이전 `HK416_*` 문서들의 OBJ 좌표, 탄창 반전 및 Grip 설정은 과거 기록입니다.
