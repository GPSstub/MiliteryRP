# 훈련용 소총 v2 — 장착·발사·장전 연출

기존 \`TrainingRifle\`을 교체하는 **동일한 Tool 1종**입니다. 새로운 무기를 중복 지급하지 않습니다. Rojo는 \`src/server\`, \`src/client\`, \`src/shared\`를 연결합니다.

## 달라진 부분
- 총구 방향이 모델의 **-Z**와 일치하도록 기존 \`Grip\`의 -90° X축 회전을 제거하고, 실제 총구 \`Muzzle\`와 탄도도 같은 기준을 사용합니다.
- 손잡이/개머리판/가늠자/리플렉스 사이트/총열/레일/방열구/탄창 등으로 모델을 개선한 **Part 조립식 로우폴리 카빈**입니다.
- 장착 시 총을 들어 올리는 연출, 사격 시 총의 순간 반동과 미세한 카메라 반동, 재장전 중 총을 기울이고 비우세 손을 움직이는 절차적 모션이 있습니다. **업로드한 Roblox 애니메이션 파일이 없는 임시 절차적 모션**이므로 실제 양손 사격 애니메이션/정밀한 1인칭 뷰모델은 후속 작업이 필요합니다.
- 서버에서 탄창을 분리했다 끼우는 \`Motor6D\` 연출과 사격 시 노리쇠 왕복 \`Motor6D\` 연출을 보여 줍니다. 총구 불꽃 파티클과 짧은 트레이서도 있습니다.
- 서버 인증된 발사와 재장전 요청에만 사운드를 재생합니다. 실제 소리 재생은 오디오 자산의 경험 권한에 따라 달라집니다.
- 조준은 **화면 중앙 십자선의 화면 레이캐스트 목표점**을 서버에 전달합니다. 서버는 실제 총구에서 해당 목표점으로 탄도를 잡아 근거리 패럴랙스(시점/총구 간격)를 보정합니다.
- 기존 30/90 발 탄약, 발사 간격 0.16초, 재장전 1.8초, 데미지 12, 같은 팀 보호 규칙은 유지합니다.

## Roblox Studio 수동 검증
1. \`git pull origin main\` 후 기존 Rojo 서버를 재연결합니다(메인 병합 후). \`ServerScriptService/TrainingRifle\`과 \`StarterPlayerScripts/TrainingRifle\`가 각각 보이는지 확인합니다.
2. **Play**에서 지급되는 \`훈련용 소총\`을 장착합니다. 카빈 총구가 플레이어의 전방을 향하는지 **R15와 R6 각각** 확인합니다. 필요하면 서버 코드의 \`BASE_GRIP\` 위치/회전을 실 게임 자세에 맞춰 조정하세요.
3. 화면 중앙 십자선으로 근거리(10~30 studs)와 원거리(100+ studs) 표적을 맞춰 탄흔과 총구 방향을 비교합니다.
4. 30발 사격 후 R 키/모바일 재장전을 확인합니다. 탄창이 빠졌다 들어가고, 총이 기울어졌다 되돌아오는지 확인합니다.
5. Output에서 오디오 로드 제한 오류를 확인하고, 필요한 경우 음원에 게임 권한을 부여하거나 ID를 바꿉니다.
6. 2명 이상 테스트로 총구 불꽃/노리쇠/탄창/사운드가 서로 보이는지, 아군 피해 보호가 유지되는지 확인합니다.
7. 화면 중앙 조준점, 통신/시험 UI, 모바일 재장전 버튼 배치를 확인합니다.

\`python3 tools/test.py\`의 Luau 컴파일과 기존 순수 상태 테스트는 GitHub Actions에서 검증합니다. **Studio 실제 1/3인칭 모델 방향과 음원 권한은 자동 테스트로 증명할 수 없습니다.**
