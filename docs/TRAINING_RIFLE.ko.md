# 훈련용 소총 1종 (MVP)

실제 군사 시스템과 독립적인 Roblox 게임 테스트용 무기입니다. **실제 총기 제작 설명이 아닙니다.**

## 기능
- 서버가 각 플레이어에게 리스폰 시 **훈련용 소총** Tool을 지급합니다.
- 모델은 기본 Roblox Part로 조립한 임시 카빈 형태입니다(외부 3D 에셋/음원 불필요).
- 장착 후 클릭/터치로 단발 발사. 자동 사격, 줌/조준, 애니메이션, 발사음은 이번 버전에 없습니다.
- 탄창 30발 / 예비 탄약 90발, 사격 간격 0.16초, 재장전 1.8초, 사거리 300 studs, 기본 피해량 12.
- `R` 키나 모바일 **재장전** 버튼으로 재장전하며, HUD에 남은 탄과 재장전 상태를 표시합니다.
- 피격은 서버 raycast로 판정하고 tracer를 아주 짧게 표시합니다. 같은 Roblox Team의 플레이어끼리는 피해를 주지 않으며 NPC Humanoid도 맞을 수 있습니다.

## 안전장치
- 탄약·발사 간격·재장전·사거리·피해량은 서버가 결정합니다. 클라이언트는 원하는 **방향**과 행동만 보냅니다.
- 살아있는 캐릭터가 서버에서 지급한 Tool을 직접 장착했을 때만 요청을 처리합니다.
- 발사 방향을 정상적인 Vector3으로 제한하며 캐릭터를 레이캐스트에서 제외합니다.
- 서버별 임시 탄약이며 새 캐릭터에는 새 탄약이 주어집니다. 기존 저장 계급, 채팅, 시험과 무관합니다.

## 설치
- `src/shared/TrainingRifleRules.luau`
- `src/server/TrainingRifle.server.luau`
- `src/client/TrainingRifle.client.luau`

기존 Rojo 또는 `python3 tools/sync_place.py`로 기존 맵에 이 스크립트들을 합칠 수 있습니다. **원본 맵을 별도로 백업하고 Studio에서 점검한 뒤 게시하세요.**

## 수동 테스트
1. 리스폰하면 Backpack에 훈련용 소총이 하나씩 들어오는지 확인
2. 장착 시 HUD가 나타나고, 미장착 시 숨겨지는지 확인
3. 총 30회 발사 후 재장전이 가능한지 확인, 사격 간격이 적용되는지 확인
4. 다른 Team의 플레이어/NPC에 명중하는지, 같은 Team 플레이어에게 피해가 없는지 확인
5. 빠르게 R 연타·발사 이벤트 위조·무장 해제 후 발사 시 서버가 거부하는지 확인
6. PC 및 모바일에서 통신/시험 UI와 HUD가 겹치지 않는지 확인

순수 규칙 테스트: `tests/training-rifle.spec.luau`. 실제 Roblox Studio 멀티플레이 실행은 별도로 필요합니다.
