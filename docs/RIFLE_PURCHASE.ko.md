# HK416 게임패스 구매자 전용 지급

`src/server/TrainingRiflePurchaseConfig.luau`의 `GAME_PASS_ID`에 **이 경험의 HK416 게임패스 ID**를 설정합니다. Developer Product ID나 Place ID는 사용할 수 없습니다. 설정한 게임패스 ID는 `2045534768` (`HK총`)입니다. 값 0으로 변경하면 지급/발사/재장전이 차단됩니다. 관리자, 제작자, Studio에 대한 무료 우회는 없습니다.

- 영구 소유권은 Roblox 게임패스로 확인하며, 추가 DataStore 구매 기록은 만들지 않습니다.
- 서버가 `UserOwnsGamePassAsync`로 소유 여부를 확인하고 소유자에게만 총을 지급합니다. 리스폰 후에도 같은 검증을 거칩니다.
- 같은 서버에서 구매하면 서버의 `PromptGamePassPurchaseFinished`를 받고 소유 여부를 다시 확인한 다음 지급합니다. 클라이언트가 구매 완료를 알리는 RemoteEvent는 없습니다.
- 총을 복제하거나 클라이언트 Attribute를 변경해도 서버의 별도 소유권 캐시가 없으면 발사/재장전 요청이 거절됩니다.
- 소유권은 30초마다 다시 조회 요청하며, 서버 권한 캐시는 60초 후 만료됩니다. Roblox 자체 API 캐시의 갱신 시점은 플랫폼 동작에 따릅니다. 조회 실패는 5초간 재시도를 제한하고 권한을 주지 않습니다. 소유권 재확인 실패/미소유 결과에는 소총을 제거합니다.
- 플레이어가 나간 뒤 늦게 도착한 API 응답은 권한을 복구하지 않습니다.
- 플레이어의 `TrainingRifleOwnershipStatus`는 owned/notOwned/checking/error/unconfigured 상태 확인용이며 클라이언트가 이 값을 바꿔도 권한이 부여되지 않습니다.

메뉴 → 게임패스에서 HK총을 구매할 수 있습니다. 가격과 판매 여부는 Roblox에서 조회하며, 보유자에게는 보유 중으로 표시합니다. 구매 창은 버튼 클릭으로만 열립니다. 서버에서 소유권을 다시 확인해야 총이 지급됩니다.

탄창은 30발, 재장전은 1.8초를 유지합니다. 예비 탄약은 무제한이며 HUD는 `30 / ∞`를 표시합니다. 발사 간격, 서버 피격 판정과 소유권 검사는 그대로 적용합니다.

## 검증

`tests/rifle-pass-access.spec.luau`는 구매자/미구매자, 플레이어 간 권한 분리, 캐시 만료, 서버 구매 확인 후 갱신, API 오류와 복구, 잘못된 상품 ID, 퇴장 후 늦은 응답을 검사합니다. Studio에서 실제 패스 소유 계정의 총 지급, 게임패스 메뉴의 보유 표시, 미보유 표시용 클라이언트 UI의 구매 버튼/조회 가격, 29발 → 재장전 → 30발과 예비 탄약 유지 상태를 확인했습니다. UI 표시 테스트는 소유권 권한 검증과 별개입니다. 유료 구매 완료 및 실제 다중 계정 통합 구매 테스트는 수행하지 않았습니다.
