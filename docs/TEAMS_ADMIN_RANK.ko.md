# 7팀 편제 및 실제 admin 계급

## 정확한 팀 목록과 배정

팀 생성/정렬 순서: **HQ → 본부 → 장관급 → 영관급 → 위관급 → 부사관급 → 병사**.

| 팀 | 기본 배정 |
|---|---|
| HQ | 실제 DataStore에 저장된 `admin` 계급 |
| 본부 | **아직 대응 계급이 없음**. 그룹 운영진이 `;팀 대상 본부`로 수동 배정 |
| 장관급 | 준장 · 소장 · 중장 · 대장 |
| 영관급 | 소령 · 중령 · 대령 |
| 위관급 | **준위** · 소위 · 중위 · 대위 |
| 부사관급 | 하사 · 중사 · 상사 · 원사 |
| 병사 | 훈련병 · 이병 · 일병 · 상병 · 병장 |

전역 팀 객체는 `src/server/TeamPolicy.luau`의 `SPECS` 배열 순서로 생성되며, 기존 Team 객체도 같은 순서로 재부모화됩니다. 사용자 요청 순서를 `TeamOrder` Attribute(1~7)에도 저장합니다. Roblox 기본 플레이어 목록은 별도 정렬 API를 제공하지 않으므로 클라이언트별 표시 순서는 Studio에서 확인해야 합니다.

## 계급 저장과 표시

- 기존 군 계급 20종의 ID와 순서를 유지합니다. **`admin`을 21번째 별도 실제 계급**으로 추가했습니다.
- 그룹 관리자 명령어 `;계급 대상 admin`을 사용하면 DataStore에 `rankId="admin"`으로 저장됩니다. `;계급 나 admin`, `;계급목록`도 지원합니다.
- `Rank`, `RankId`, `RankDisplayId`, `leaderstats/계급`은 실제 저장 계급 기준입니다. **HQ 팀에 들어갔다고 임의로 admin으로 표시하지 않습니다.**
- 기존 20개 계급장을 담은 이미지 아틀라스 순서를 변경하지 않습니다. `admin`은 아틀라스 밖의 별도 표기로 유지하며, HQ 로고와 실제 계급 텍스트가 머리 위에 보입니다.
- `RankService`가 DataStore 복원 및 명령어로 변경한 `RankId`와 `RankCategory`를 서버에 발행하면 `TeamService`는 해당 **계급의 팀으로 자동 배정**합니다.
- 수동 `;팀` 명령은 세션의 팀만 변경하고 실제 계급/저장 데이터/명령어 권한을 변경하지 않습니다. **그다음 계급 변경 시 수동 팀 지정은 해제**됩니다.
- 이전 코드의 제작자 UserId만으로 HQ에 강제 배정하던 예외를 제거했습니다. `admin` 계급으로 배정해야 HQ 자동 편제가 이루어집니다.

## 관리자 명령 권한은 별개

계급 `admin` 또는 HQ/본부 팀이라고 **관리자 명령이 허용되지 않습니다**. `AdminGroupPolicy.luau`는 여전히 Roblox 그룹 `1101574390`의 랭크 **200 이상**만 운영진 명령을 허용합니다. 일반 계급을 바꾸거나 팀을 옮겨도 그룹 등급은 바뀌지 않습니다.

## 확인 방법

1. GitHub `main`을 `git pull --ff-only origin main`으로 갱신하고 Rojo `default.project.json`으로 동기화합니다.
2. Edit → Play를 **완전히 재시작**합니다. Explorer `Teams`에서 7개 팀 및 `TeamOrder` 속성을 확인합니다.
3. 서버 그룹 관리자로 `;계급 나 admin` 실행 후 `RankId=admin`, `Rank=admin`, Team=HQ 확인. `;계급 나 병장`으로 변경하면 Team=병사/Rank=병장인지 확인합니다.
4. `;팀 나 본부`를 실행하여 실제 계급은 그대로이고 Team만 본부인지 확인합니다. `;계급 나 준위`를 실행하면 Team=위관급으로 자동 복귀하는지 확인합니다.
5. `;계급 나 하사` → 부사관급, `;계급 나 대령` → 영관급, `;계급 나 준장` → 장관급을 확인합니다.
6. 그룹 운영진 권한이 없는 사용자에게 `admin` 계급 또는 HQ 팀만 부여해도 `;무적`/운영진 패널 명령은 거절되어야 합니다.

**주의:** 로컬 Studio `MilitaryRP.rbxlx`에 이미 저장된 Script와 원격 GitHub Rojo 소스가 다를 수 있습니다. 이 기능은 `src` 코드를 Rojo로 동기화한 상태에서 적용됩니다. 완성 맵은 `tools/build_place.py`로 덮어쓰지 마세요.
