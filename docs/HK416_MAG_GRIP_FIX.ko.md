# HK416 R15 총구 각도 및 탄창 삽입구 보정

2026-10-21 제공된 **R15 게임 캡처**에서는 총구가 캐릭터 전방 기준 위로 들려 있고, 탄창의 상단이 리시버 밑으로 분리돼 보였습니다.

## 왜 그랬는가

- 총몸 FBX와 탄창 FBX는 서로 독립적인 원본 좌표계였고, 기존 합성 OBJ에서 탄창의 윗끝은 모델 중심 기준 **Y=-0.329**까지밖에 오르지 않았습니다.
- `src/server/TrainingRifle.server.luau`에 저장된 탄창 중심 Y=-1.041은 메시가 총몸에 충분히 끼워진 상태가 아니었습니다. 발사/장전 코드는 이를 그대로 Motor6D 기본 위치로 사용했습니다.
- 앞서 총을 뒤집기 위해 적용한 Yaw 180°만으로는 Roblox R15 오른손 그립의 기울기(스크린샷상 약 15° 위)를 보정하지 못했습니다.

## 이번 수정

| 항목 | 이전 | 현재 |
|---|---:|---:|
| `R15_GRIP_YAW_DEGREES` | 180° | 180° |
| `R15_GRIP_PITCH_DEGREES` | 0° | **-14°** |
| `BASE_GRIP` 위치 | (0, -0.22, -0.40) | **(0, -0.30, -0.43)** |
| `HK416_MAG_INSERTION_LIFT` | 0 | **+0.29 원본 OBJ 유닛** |
| `HK416_MESH_SCALE` | 0.64 | 0.64 |

탄창 위끝은 원본 기준 약 Y=-0.039까지 올라가므로 리시버 하단에 겹쳐 들어갑니다. 위치는 **탄창 Motor6D의 C0 기본 포즈**에 적용되어 장전 후에도 같은 자리로 복귀합니다. 탄창 자체 MeshPart/모델 파일은 바꾸지 않습니다. 본 보정은 업로드된 OBJ 좌표와 스크린샷에 의거한 초깃값이며, 실제 Roblox Studio의 아바타 스케일·총 잡는 자세에 따른 미세 조정은 필요할 수 있습니다.

## 테스트

1. Studio에서 Play 중지, 코드 pull, Rojo 재연결, Play 재시작. `ServerStorage/HK416Assets`는 그대로 둡니다.
2. 장착된 훈련용 소총 `Tool`의 속성에서 `GripPitchDegrees=-14`, `MagazineInsertionLift=0.29`, `UsingHK416Mesh=true`인지 확인합니다.
3. 옆에서 관찰할 때 총구가 거의 수평을 향하고 탄창 윗부분이 삽입구로 들어갔는지 확인합니다.
4. R 키 재장전 → 탄창 분리 및 복귀, 다시 사격 → 총구 불꽃이 총끝에서 나오는지 확인합니다.

**모델이 더 낮거나 높게 보이면** `R15_GRIP_PITCH_DEGREES`를 2~3도 단위로 미세 조정할 수 있습니다(현재 -14°, 값이 더 작으면 총구가 더 아래를 향함). **탄창이 덜 들어가면** `HK416_MAG_INSERTION_LIFT`를 0.05 단위로 높이거나 낮출 수 있습니다. 조정 후에는 Play를 다시 시작해야 합니다.

Studio 실제 플레이는 GitHub CI만으로 검증되지 않습니다.
